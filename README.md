# 📚 智能教学辅助系统（EducationSystem）

> 一个把「计算机系统功能」与「教师课堂讲授」相结合的在线教学辅助平台，为学生课后主动学习与师生互动提供支撑。

## ✨ 项目简介

- 学生课后可通过本系统**反复巩固**课堂上未掌握的知识点，也可**针对自己的问题直接向老师提问交流**；
- 老师可**回复学生提问**，解决学生在课堂内没有解决的学习问题；
- 系统**界面简洁、操作方便**，可满足广大学生与老师的教学辅助需求；
- 弥补了传统教学方式**单一、片面**的缺点，帮助学生在课后自主学习、提高学习效率，也帮助老师提升教学质量，助力互联网教育发展。

## 🧩 功能一览

| 角色 | 功能 |
| --- | --- |
| 通用 | 登录（含登录拦截器）、退出登录、欢迎登录名显示 |
| 管理员 | 登录账户信息管理（查询/添加/删除/修改）、学生信息管理、老师信息管理、重置老师登录密码 |
| 老师 | 教学课件管理（上传/查看/新增/删除/修改）、教学视频管理（上传/查看/删除/修改）、师生交流管理（查看留言/删除问答/回答问题/修改答案）、修改登录密码 |
| 学生 | 课件下载、视频下载、师生交流、向老师提问、查看/修改个人信息、修改登录密码 |

## 🛠 技术栈

| 分类 | 技术 |
| --- | --- |
| 后端框架 | Spring Boot（Java 8） |
| 视图层 | Thymeleaf / JSP（JSTL + Jasper） |
| ORM | MyBatis + MyBatis Generator + PageHelper 分页 |
| 数据库 | MySQL（库名 `educational`） |
| 连接池 | Druid |
| 文件上传 | commons-fileupload（课件 / 视频上传下载） |
| 其他 | Lombok、commons-codec、spring-boot-devtools |

## 📁 项目结构

```
src/main/java/com/kdgx
├── controller    # 控制器
├── service       # 业务层（+ impl）
├── mapper        # MyBatis 数据访问接口
├── entity        # 实体类
├── loginconfig / loginInter   # 登录配置与登录拦截器
└── util          # 工具类
src/main/resources
├── application.yml   # 端口 / 数据库 / 上传配置
├── mapper/*.xml      # MyBatis SQL
├── static            # 前端静态资源（css / js / img）
└── templates         # 页面模板
```

## ⚙️ 运行方式

1. 环境要求：JDK 8+、MySQL
2. 修改 `src/main/resources/application.yml` 中数据库连接为你的 MySQL 账号密码（默认库名 `educational`）
3. 启动：
   - Windows：`mvnw.cmd spring-boot:run`
   - macOS / Linux：`./mvnw spring-boot:run`
4. 浏览器访问：http://localhost:8001
